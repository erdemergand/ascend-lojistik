# Welcome to your Lovable project

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable

Open your project in the [Lovable editor](https://lovable.dev) and keep building.

- **Ship faster**: describe what you want to build and Lovable handles the code.
- **Stay in sync**: connect the project to GitHub and every change made in Lovable is committed straight to your repository.
- **Full ownership**: this code is yours. Automatic sync requires a separately configured Lovable GitHub connection; the source export alone does not establish it.

## Development

Yerel kurulum için [DEVELOPMENT.md](DEVELOPMENT.md), korunacak proje bağlamı için [AGENTS.md](AGENTS.md) dosyasını okuyun. Mevcut lockfile nedeniyle Bun kullanılır.

```sh
git clone https://github.com/erdemergand/ascend-lojistik.git
cd ascend-lojistik
bun install --frozen-lockfile
bun run dev --host 127.0.0.1
```
